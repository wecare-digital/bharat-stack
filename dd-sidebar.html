Dashboard sidebar — existing vs fixed

There is no separate dashboard "header" — the dashboard chrome is the sidebar. It has the same defects we just fixed on the public header, plus one worse one.

Real bugs found in the dashboard sidebar:
  • Active vs hover nearly identical — hover is rgba(209,244,112,.2), active .3. Almost indistinguishable.
  • Active state is INVISIBLE on expandable rows and sub-items — an !important transparent rule kills it, so the page you're on shows no highlight at all (see "Payments" and "Message logs" on the left).
  • Section labels are faint grey #9ca3af, unlike the public header's deep-green headers.
  • Sidebar scrollbar is grey, not the lime theme.
  • Brand chevron is a literal ▼ text glyph — the public header uses a drawn chevron.
