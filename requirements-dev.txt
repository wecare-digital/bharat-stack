# Local development / test environment for the Python side of this repo.
#
# Recreate with:
#     python3.12 -m venv .venv
#     .venv/bin/python -m pip install -r requirements-dev.txt
#
# THIS FILE DOES NOT DEFINE THE LAMBDA RUNTIME.
# The deploy scripts bundle only handler.py, lambda_utils/,
# static_knowledge_base.py and a function's own modules//flows/ directory - no
# third-party packages. Anything here that a handler needs at runtime has to be
# supplied by the python3.12 runtime itself (boto3/botocore) or by a Lambda
# layer, the way PIL comes from pillow-python312 and cryptography from
# cryptography-python312. Adding a package here does NOT make it importable in
# production.
#
# Notes on specific pins:
#   awscrt            - the botocore[crt] extra. Required because the
#                       sso-session in ~/.aws/config makes botocore load its
#                       login credential provider at import time.
#   pydantic-core     - cannot be bumped independently; pydantic==2.13.5 (the
#                       current release) hard-pins pydantic-core==2.46.5, so
#                       `pip list --outdated` reporting 2.49.0 is a false
#                       positive.
#   facebook_business - Meta's official SDK, targets Graph v26.0. Currently
#                       unused: every Graph call in this repo is raw urllib in
#                       lambda_utils/meta_client.py.
#
