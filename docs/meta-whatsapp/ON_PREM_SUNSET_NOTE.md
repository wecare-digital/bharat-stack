# On-Premises API Sunset

Ref: https://developers.facebook.com/docs/whatsapp/on-premises/sunset/

**This repository does not use the WhatsApp On-Premises API.** All messaging uses the **Cloud API** (Meta Graph `v25.0`) via AWS End User Messaging for inbound and direct Graph calls for outbound.

Status: `DEPRECATED_NOT_BUILT` / `NOT_APPLICABLE`.

Action required: none for this codebase. No On-Prem client, no Coreapp/Webapp containers, no On-Prem media endpoints are present. If any third-party integration still references On-Prem, it is out of scope here.
